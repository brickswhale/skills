# learn

A lesson that lives where nothing reads it is not a lesson.

1. **Start from the class.** One occurrence is an anecdote. Name the class, count its members with a command, report the number. Count of one: say so and stop. No durable control warranted: give the evidence and stop.
2. **Check what exists, then take the highest rung that can catch this class.** A rule that went unread is a loading failure, not a missing one: raise it to a rung nothing can skip, never duplicate it. Each lower rung needs something to choose to read it, which is why it is weaker:
   - **a test** that fails when the class comes back.
   - **a hook or lint rule** that blocks it as it happens.
   - **a line in a skill** the work already loads.
   - **a line in the project briefing.**
   A rung counts only if it can see the mistake. Name the rungs you ruled out and why.
3. **Prefer replacement.** Name the line superseded. If none exists, say so and justify the addition.
4. **Write the rule, not the story.** Say what to do, in the words of the moment it applies.
5. **One rule per class.** Two classes are two passes.
6. **Report** the class, its count, the rung taken, the rungs ruled out, and the exact change: replacement, addition, or loading fix.
