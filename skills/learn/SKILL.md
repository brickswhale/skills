# learn

A lesson that lives where nothing reads it is not a lesson.

1. **Start from the class.** One occurrence is an anecdote. Name the class, count its members with a command, report the number. Count of one: say so and stop — wait for the second.
2. **Take the highest rung that can catch this class.** Each rung down needs something to choose to read it at the right moment, which is why it is weaker:
   - **a test** that fails when the class comes back.
   - **a hook or lint rule** that blocks it as it happens.
   - **a line in a skill** the work already loads.
   - **a line in the project briefing.**
   A rung counts only if it can see the mistake. Name the rungs you ruled out and why.
3. **Replace, never add.** Find the line the new one supersedes and name it. A briefing that only grows stops being read, and last week's addition is already invisible.
4. **Write the rule, not the story.** Say what to do, in the words of the moment it applies. "Count the siblings before proposing the fix" beats "on Tuesday we patched one of three call sites".
5. **One rule per class.** Two classes are two passes.
6. **Report** the class, its count, the rung taken, the rungs ruled out, and the exact line replaced.
